# demo-core

Local intentionally imperfect bank-like proxy UI.

**Phase 1:** placeholder static page on `http://127.0.0.1:4173` only.  
**Phase 11:** multi-step flows, legacy-hostile markup, injectable exceptional states (not-found, validation, permission, interstitial, session expiry, slowness).

Start from repo root:

```bash
npm run demo:core
```
